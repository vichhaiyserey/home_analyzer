# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-08-08

### Added
- Feature to delete selected files directly with UI confirmation modal (`/delete` endpoint).
- Multi-file selection support with floating action toolbar showing total count & size.
- Sample screenshot for Windows platform (`samples/sample-windows.jpeg`).

## [1.0.0] - 2026-07-25

### Added
- Storage breakdown by file type.
- Largest files list.
- Recently changed files overview.
- Old & heavy files identification (untouched for 1+ year).
- Smart exclusions filter for hidden & system directories.
- Cross-platform support (macOS, Windows, Linux).
- One-page Flask local web UI.
- Open-source licensing (MIT) and community governance documents.
